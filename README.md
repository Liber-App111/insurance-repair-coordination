# Post-Settlement Repair Coordination — validation landing page

This is a zero-cost static landing page intended for early market validation.

## Files

- `index.html` — page content
- `styles.css` — visual design
- `assets/` — replaceable image assets

## Before publishing

1. Create a free Tally form.
2. Replace `https://tally.so/r/REPLACE-ME` in `index.html` with the real Tally URL.
3. Replace the two image-placeholder blocks with approved property/repair photography when ready.
4. Review regulatory and licensing wording before commercial launch.
5. Upload the repository to GitHub and enable GitHub Pages.

## No framework required

The site uses plain HTML and CSS. There is no build step, package manager, server, database, or paid hosting requirement.
